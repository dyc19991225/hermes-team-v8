## 已知失败与未确认项

初次验收之后，一个 Codex 只读探测任务曾报告 JSON-RPC `lone leading surrogate` 反序列化错误，随后在 90 秒超时退出。已保留的记录未确定完整根因。V8.1 修复了另行复现的标准流编码和异常 Unicode 结果持久化问题，并通过对应回归和一次真实只读调用；这不证明历史 JSON-RPC 失败与这些问题具有同一个根因。

Codex 适配器初次验收针对本机 0.167.0 协议；Claude Code 和 AGY 的历史版本分别为 2.1.319、1.5.5。这些仅对应初次验收，不是推荐安装版本；V8.1 的实际版本另见上文。

当前仍缺少：

- CLI 升级后的全套在线兼容性与文件边界复测。
- 长时间运行、长时间队列接续及并发调度的验收；本次已覆盖短任务串行接续与验收释放依赖的本地集成场景。
- 成本、完成率、视觉质量和人工干预次数的对照基准。
- 通用安装器、跨平台运行与独立第三方在线复现；本仓库现已提供 Windows 离线测试入口。

## 阅读这些结果时的边界

本地回归通过，支持的是测试所覆盖的代码行为；历史在线验收，支持的是当时环境中的对应场景；产品质量、完整主机隔离与实际成本，需要另外的证据。仓库中的示例配置为虚构数据，不是生产配置或已执行任务。
