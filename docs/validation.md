## 已知失败与未确认项

初次验收之后，一个 Codex 只读探测任务曾报告 JSON-RPC `lone leading surrogate` 反序列化错误，随后在 90 秒超时退出。已保留的记录未确定根因。后续修改的是状态观察与主控规则，不能据此宣称编码问题已修复。

Codex 适配器初次验收针对本机 0.167.0 协议；Claude Code 和 AGY 的历史版本分别为 2.1.319、1.5.5。这些是当时记录的版本，不是本次对当前 CLI 版本的重新确认，也不是推荐安装版本。

当前仍缺少：

- CLI 升级后的全套在线兼容性与文件边界复测。
- 长时间运行、自动排队及并发调度的验收。
- 成本、完成率、视觉质量和人工干预次数的对照基准。
- 通用安装器、跨平台运行与独立第三方复现。

## 阅读这些结果时的边界

本地回归通过，支持的是测试所覆盖的代码行为；历史在线验收，支持的是当时环境中的对应场景；产品质量、完整主机隔离与实际成本，需要另外的证据。仓库中的示例配置为虚构数据，不是生产配置或已执行任务。
